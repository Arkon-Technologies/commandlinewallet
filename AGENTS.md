# Repository agent guidance

This repository is controlled by `dhanushonchain`. Agents may inspect and edit local files and run local Rust validation. Do not commit, push, pull, fetch, create or merge pull requests, create issues or releases, or perform GitHub write operations. Do not alter remotes, authentication, Git identity, or collaborators.

Maintain the Phase 1 boundary until a later phase is explicitly authorized: no live wallet generation, private-key storage, cryptographic signing, or broadcasting. Do not describe planned interfaces as active protections. Keep signing separate from network-facing code and never log or display secret material.
